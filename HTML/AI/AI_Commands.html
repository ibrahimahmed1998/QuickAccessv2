CommandDescription
/initScans the project and generates/updates the base instructions file (e.g. CLAUDE.md) so the assistant understands the repo's structure and conventions.
/planAsks the assistant to produce a step-by-step plan for a task before any code is written, so it can be reviewed and approved first.
/rubber-duckStarts a rubber-duck style dialogue where you explain the problem out loud to clarify your own thinking before implementing a fix.
/setup-matt-pocock-skillsInstalls Matt Pocock's community skill pack, adding a curated set of prebuilt skills to the assistant.
/goalSets or displays the current high-level goal/objective that should guide the session's work.
/workflowDefines or runs a named multi-step workflow that chains several actions together.
/compactCompacts/summarizes the conversation history to free up context window space while keeping key details.
/agentsLists the available subagents and lets you inspect, create, or switch between them.
/skillsLists installed skills/plugins and lets you enable, disable, or manage them.
CommandDescription
/modelShows the active AI model or switches to a different one for the session.
/effortsSets or views the reasoning-effort level (e.g. low/medium/high) used when generating responses.
/statusShows the current session status, including active model, context usage, and connected tools.
/usageDisplays token/request usage statistics and remaining limits for the account or session.
