How to extend this glossary

Use Add concept to enter a title, definition, example, and optional category. Additions stay in this open page. Choose Download HTML to save a standalone copy containing all entries, including your additions. Closing the page without downloading loses unsaved additions.

For bulk editing, open the HTML in a text editor and append objects to the concept-data JSON array. Each object uses title, definition, example, and category. Pagination and category filters update automatically. Keep the JSON valid and escape any literal < character as \u003c inside that data block.

This is a broad starting glossary, not an exhaustive list of every AI term. Definitions are concise learning aids; examples are illustrative.
